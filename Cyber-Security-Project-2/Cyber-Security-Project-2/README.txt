# Cyber Security Project 2
## Basic Encryption and Decryption

**Project Name:** Basic Encryption & Decryption  
**Technology Used:** Python  
**Encryption Technique:** Caesar Cipher

### Project Description
This project implements a basic encryption and decryption technique using the Caesar Cipher. It accepts a message from the user, encrypts the message using a shift key, and decrypts it to recover the original message.

### Features
- Takes text input from the user.
- Accepts a shift key between 0 and 25.
- Encrypts uppercase and lowercase letters.
- Preserves spaces, numbers, and symbols.
- Decrypts the encrypted message.
- Displays original, encrypted, and decrypted text.
- Validates the input and shift key.

### How to Run
1. Install Python.
2. Open a terminal in the project folder.
3. Run the command: `python project2.py`
4. Enter a message and a shift key.
5. Check the displayed results.

### Expected Result
The decrypted message should match the original message.

### Learning Outcomes
Understanding basic encryption, decryption, character manipulation, and programming logic.
